## Khi review bài này

- PR chỉ sửa `ABOUT.md`. File khác bị sửa (ví dụ `README.md`) thì nhắc thành viên tách ra.
- Tiêu đề PR nói rõ việc đã làm, không để mặc định "Update ABOUT.md".
- Commit message viết ở thể mệnh lệnh: "Add ABOUT.md", không phải "added file".

## Lỗi hay gặp

- Mở PR vào repo template gốc thay vì repo của mình: chỉ lại chỗ chọn base repository.
- Commit thẳng lên `main` rồi không còn gì để mở PR: hướng dẫn tạo nhánh mới và làm lại.

Ghi chú này công khai trong repo nội dung: đừng viết đáp án cần giấu ở đây.
